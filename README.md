# Taller de Visualización de Datos en Power BI
*Por: Camilo Andrés González López*

## Descripción
Taller enfocado en la preparación, transformación y visualización de datos comerciales mediante Python en Google Colab y Power BI, utilizando el conjunto de datos **SuperStoreUS-2015**, obtenido de `"https://hackernoon.com/13-best-datasets-for-power-bi-practice"`.

## Herramientas utilizadas
- **Python y Pandas:** limpieza y transformación de datos (ETL).
- **Google Colab:** desarrollo del proceso de preparación de datos.
- **Power BI:** modelado, visualización y análisis de información.
- **Excel:** almacenamiento y exportación de los datos procesados.

## Contenido del repositorio
- `Taller_Visualizacion_PowerBI.ipynb`: notebook con el proceso ETL.
- `SuperStoreUS_2015.xlsx`: archivo con los datos crudos, antes de realizar el proceso ETL.
- `SuperStoreUS_2015_ETL_PowerBI.xlsx`: archivo con los datos procesados por el código en Colab, preparado para ser llevado a PowerBI y crear el tablero de análisis.

## Resultados
Se desarrolló un proceso de preparación de datos y un tablero interactivo para analizar ventas, ganancias, productos, clientes, regiones y métodos de envío, facilitando la interpretación de los resultados y la identificación de oportunidades de mejora.
